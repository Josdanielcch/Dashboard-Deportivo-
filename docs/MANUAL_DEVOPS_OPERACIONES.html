02 Procedimiento de Despliegue en Servidor Linux

1. Configuración de PM2 para el Backend Producción 
cd /var/www/courtmanager/Backend
npm install --omit=dev
pm2 start server.js --name "courtmanager-api" -i max
pm2 save && pm2 startup
2. Configuración de Nginx con Soporte WebSockets Reverse Proxy 
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}

03 Estrategia de Respaldo y Recuperación ante Desastres

📦 Respaldo Frío Programado (pg_dump)
pg_dump "$DATABASE_URL" \
  -F c -b -v \
  -f "/var/backups/db_$(date +%Y%m%d).dump"

Se ejecuta diariamente mediante un cron job nocturno y se sincroniza con almacenamiento S3 secundario.

⚡ Rebobinado Instantáneo en Neon

Point-in-Time Recovery (PITR) nativo en Neon Cloud. Si un operador elimina accidentalmente datos, la base de datos puede rebobinarse al segundo exacto anterior al error en menos de 2 minutos.

04 Matriz de Resolución de Incidentes Críticos

Falla Detectada Causa Raíz Acción de Mitigación
502 Bad Gateway Proceso Node.js caído por error no capturado. pm2 reload courtmanager-api y revisar pm2 logs.
Sockets Caídos Falta directiva Upgrade en Nginx. Verificar bloque Connection "upgrade" en config de Nginx.
CORS Denied Dominio nuevo no listado en .env. Agregar la URL completa en CORS_ORIGINS y recargar.
Correos en Cola Límite diario alcanzado en Brevo. Actualizar plan en Brevo o verificar credenciales SMTP.
